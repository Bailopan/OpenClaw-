# Supplier Radar

Автоматический поиск производителей, оптовиков, дистрибьюторов и реальных складов. Первый контур — Пушкино и северо-восток Московской области.

## Архитектура

`Yandex Cloud Timer → Serverless Container → deferred Yandex Search API → Python query branches → domain dedupe → page enrichment → optional Google Sheets`

LLM в v1 намеренно не используется: сначала дешёвый массовый сбор и детерминированная фильтрация. ChatGPT подключается только к спорным/лучшим кандидатам.

## Что ищем

Ветка A–R включает прямой поиск, brand/legal entity, адресные кластеры, промзоны, соседние города, PDF/XLS прайсы, каталоги, reverse entity, ОКВЭД/ИНН, декларации, товарные знаки, вакансии, складскую недвижимость, ассоциации/выставки, закупки, логистические следы и distributor/manufacturer маршруты.

## Безопасность и бюджет

- секреты не хранятся в GitHub;
- Search API по умолчанию — deferred;
- максимум 100 Search API запросов за прогон;
- программный лимит 10 ₽/прогон;
- целевой лимит 100 ₽/сутки;
- сайты обогащаются максимум по одной публичной странице на домен, с ограниченной конкурентностью.
